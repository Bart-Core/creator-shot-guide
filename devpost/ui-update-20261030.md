# Readability and placement update

The apparent dotted overlap in the room demo was television artwork visible through additive AR, not duplicate control pages. An isolated native render established this distinction.

The control panel now uses the existing UIKit Frame. Aim at its border, pinch and drag to a calmer background; controls remain inside. Active duration options have stronger contrast. Closing, scaling and follow buttons are disabled to avoid accidental loss of the tool. No new dependency.

49 independent native Preview assertions passed against this version, including marker movement, immutable reference replay, changed-plan replay and cancellation. A separate native hover/pinch/drag/release test changed the Frame's runtime position. A successful transport response alone was not accepted as evidence: a first gesture without hover acquisition did not move the panel and remains a failed test.

This is Preview evidence, not headset validation. Additive AR still cannot hide the physical background. The video shown in README is the previous presentation until a new actual recording is verified.
